# Lead Management & Email Automation Dashboard

A full-stack web application designed to simplify lead management and email outreach through a centralized and user-friendly dashboard.

The platform allows users to manage leads, import contact data using CSV files, organize lead information, create email campaigns, and streamline communication through Gmail integration.

## 🚀 Features

- 📊 Lead Management
- 📥 CSV Lead Import
- 📧 Email Campaign Creation
- 📬 Gmail Integration
- 🔐 User Authentication
- 🎯 Targeted Lead Outreach
- 📋 Lead Organization and Tracking
- 📱 Responsive Dashboard
- ⚡ Modern and Interactive UI
